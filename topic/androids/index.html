Programmable Androids

Automate tasks with robots

Programmable Androids Place an android, then open it to edit its Memory Core - a script of actions it repeats.

Actions include turning, moving, digging, mining, farming, chopping trees, fishing and attacking. The script loops from start to finish forever.

Androids run on fuel (coal, lava, even nuclear fuel on higher tiers). Higher tiers burn fuel more efficiently.

Professions Miner, Farmer, Woodcutter, Butcher and Fisherman.

Interfaces Place Android Interfaces next to it: a fuel interface to refuel it, an item interface to collect its output.

The Programmable Androids category contains robots that are able to automate tasks.
