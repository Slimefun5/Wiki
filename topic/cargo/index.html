Cargo Networks

Move items automatically

Cargo Networks A Cargo Network moves items between chests and machines automatically.

Building it Place a Cargo Manager - the core, like the Energy Regulator. Attach nodes to the faces of chests and machines, and link everything with Cargo Nodes within 5 blocks.

The two terminal nodes - Input Node: pulls items OUT of the block it is on. - Output Node: deposits items INTO the block it is on.

Channels Each node has a channel (0-15). Items pulled on a channel only go to Outputs on the SAME channel. Use channels to keep item streams separate.

Filtering Input Nodes and the Advanced Output Node have a filter: - Whitelist: only listed items - Blacklist: block listed items (The basic Output Node accepts anything.)

Example: auto-sorter Input Node on a source chest, channel 0. Add an Advanced Output per item type, channel 0, each whitelisting one item. They sort themselves into chests.

Cargo Management is Slimefun5's item transportation system.
With it, you can quickly and automatically move items between containers or machines over virtually any distance.

A cargo management network requires a cargo manager. It allows items to be transported and gives you information about your network.

Placing input and output nodes on a container or machine allows the items in it to enter or exit the network, respectively. These nodes have to be in the direct range of a cargo manager, or they can be connected to one with connector nodes.

Items in a cargo network are transported over a maximum of 16 separate channels, each labelled with a different color of wool.
