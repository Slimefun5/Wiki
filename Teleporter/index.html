Teleporter

The Teleporter is a Multiblock GPS-based device.

Obtaining

A Teleporter is created by placing a GPS Teleporter Matrix encircled by eight GPS Teleporter Pylons, and placing a GPS Activation Device on the GPS Teleporter Matrix.

Usage

Teleporters are used to teleport to waypoints created using a GPS Marker Tool or a GPS Emergency Transmitter.

Teleporting speed is determined by the distance of the given waypoint and the GPS network complexity.
If the network complexity is lower than 100, it will always take 50 seconds to teleport.
