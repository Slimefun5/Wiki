Normal Androids

A Normal Android is used as a base to create a specialized Android.

Obtaining

Normal Androids can be crafted in an Enhanced Crafting Table.

Usage

Normal Androids can only be programmed to move. Androids need fuel in order to work, you have to fill them with the Required Fuel before booting!

Tiers

There are three tiers on the Normal Android, each with different modifiers listed below.

Tier Fuel Efficiency
Basic 1.0x
Advanced 1.5x
Empowered 3.0x

Power Source

Each tier requires different types of fuel, their possible fuels are listed below.
