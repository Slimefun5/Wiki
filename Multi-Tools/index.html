Multi Tools

Multi Tools are part of the Technical Gadgets category. They need to be charged in a Charging Bench before usage.

Right-click to use. Crouch + right-click to switch modes. Each time you use it, it will use up 0.3 J of its stored energy.

The Multi Tool has 4 modes:

  • Portable Crafter Mode
  • Magic Eye of Ender mode
  • Elemental Staff - Wind Mode
  • Grappling Hook Mode
