A multiblock Gold Pan and Nether Gold Pan in one. Pans gravel and soul sand without doing it by hand.

The Automated Panning Machine is in the Basic Machines category. It is a multiblock structure.
It's an automated version of the Gold Pan and the Nether Gold Pan.

Obtaining

The Automated Panning Machine is a multiblock structure, it consists of a cauldron and a trapdoor. Trapdoor can be of any wood type.

A complete setup should look like this:

You can also place an Output Chest next to the cauldron to collect your items. If there is no Output Chest, then it will be thrown on top of the trapdoor.

Usage

It's a faster version of the Gold Pan and the Nether Gold Pan and has the exact same usages as them combined.
To use the Automated Panning Machine, right click trapdoor with any block that is convertable, it will then proceed to output its converted items after a small animation.
