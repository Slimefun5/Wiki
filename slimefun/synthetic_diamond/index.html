Synthetic DiamondSlimefunDocumented

  • Resource
  • This item can be used in a
  • workbench and acts like a normal Diamond

The Synthetic Diamond is a Resource that can substitute the minecraft diamond in the workbench. It is also used to craft various Slimefun5 items.

Obtaining

The Synthetic Diamond can be crafted in the Pressure Chamber using 1 Carbon Chunk.
