Charging BenchSlimefunDocumented

  • Machine
  • Charges Items such as Jetpacks
  • ⇨ ⚡ 128 J Buffer
  • ⇨ ⚡ Energy Loss: 50%

The Charging Bench is an Electric Machine which can be used to charge items like bacpacks.

Tiers

It currently only comes in one tier. Energy loss means that if you want to charge an item for 100 J, it will cost 200 J in power.

Buffer: 128 J
Energy Loss: 50%
