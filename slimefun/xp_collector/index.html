EXP CollectorSlimefunDocumented

  • Machine
  • Collects nearby Exp and stores it
  • ⇨ ⚡ 1024 J Buffer
  • ⇨ ⚡ 20 J/s

The EXP-Collector is an Electric Machine which can be used to collect exp.
It stores the exp in Flasks of Knowledge.

EXP-Collector Tiers

The EXP-Collector currently only has one tier.

Power Usage: 20 J/Sf Tick Power Buffer: 1024 J
