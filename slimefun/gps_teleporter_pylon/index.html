GPS Teleporter PylonSlimefunDocumented

  • Component

A structural component used to build a GPS Teleporter. Place several around the matrix.

The GPS Teleporter Pylon is a block added in the GPS category.

Obtaining

The GPS Teleporter Pylon can be crafted in groups of eight in an Enhanced Crafting Table.

Usage

The GPS Teleporter Pylon is a component of a Teleporter.
