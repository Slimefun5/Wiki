JuicerSlimefunDocumented

  • Multiblock
  • Allows you to create delicious Juice

A multiblock for turning fruit into refreshing juices. Right-click with the ingredients to make a drink.

The Juicer is a Basic Machine which can be used to create juices from certain fruits.

Obtaining

The Juicer is a multiblock structure, it consists of a dispenser, a nether brick fence and some glass.

You can also place an Output Chest next to the dispenser to collect the juices.
