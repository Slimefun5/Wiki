A Cargo Motor is an item in the Cargo Management category.
It is a crafting ingredient in cargo-related and electric machine recipes.

Obtaining

Cargo motors can be crafted in groups of four in an Enhanced Crafting Table.

Usage

Cargo motors are used in the following recipes: * Advanced Cargo Node (Output) * Cargo Manager * Cargo Node (Connector) * Fluid Pump * Reactor Access Port * Trash Can
