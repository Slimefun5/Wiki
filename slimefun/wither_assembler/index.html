Wither AssemblerSlimefunDocumented

  • Machine
  • Assembles a Wither from Wither Skeleton
  • Skulls and Soul Sand using stored energy.
  • ⇨ Cooldown: 30 Seconds
  • ⇨ ⚡ 4096 J Buffer
  • ⇨ ⚡ 4096 J/Wither

The Wither Assembler is an Electric Machine which can be used to automatically assemble withers.
This is an End-Game machine and should be handled cautiously.

Tiers

It currently only comes in one tier.

Buffer: 4096 J
Power Usage: 4096 J/wither
Cooldown: 30s
