Electric FurnaceSlimefunDocumented

  • Machine
  • Automatically smelts items like a furnace.
  • ⇨ ⚡ Speed: 1.0x
  • ⇨ ⚡ 4 J/s

Smelts items using energy instead of fuel. Connect it to an energy network and add items to smelt.

The Electric Furnace is an Electric Machine which smelts items by using electricity.

This machine is practically a vanilla minecraft furnace, the only difference being the fact that it runs on electricity instead of fuel.
