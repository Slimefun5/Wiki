GPS Geo-ScannerSlimefunDocumented

  • Gadget
  • Scans a Chunk for natural Resources
  • such as Oil

Scans the current chunk for buried resources like oil. Scan before placing a GEO Miner.

The GPS Geo-Scanner is a placeable tool added in the GPS category.

Obtaining

The GPS Geo-Scanner can be crafted in an Enhanced Crafting Table.

Usage

Right-Clicking on a placed GPS Geo-Scanner opens a chest GUI with the overview of mineable resources of a given chunk.

These resources are only obtainable using an Oil Pump or a GEO Miner.

Scanning requires a GPS network complexity of at least 600.
