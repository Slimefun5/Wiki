Place it to set a GPS waypoint at that exact location. Mark spots for later teleporting.

The GPS Marker Tool is a tool in the GPS category.

Obtaining

The GPS Marker Tool can be crafted in an Enhanced Crafting Table.

Usage

GPS Marker Tool is used to create waypoints used by a Teleporter.

Right-Clicking with the GPS Marker Tool prompts the user to write a name for their waypoint in the chat, which is subsequently added to their waypoints.
Waypoints support color codes.
