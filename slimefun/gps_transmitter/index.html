GPS TransmitterSlimefunDocumented

  • Machine
  • Broadcasts your location to the GPS network,
  • allowing you to set Waypoints.
  • ⇨ ⚡ 16 J Buffer
  • ⇨ ⚡ 2 J/s

Place and power it to put a satellite into orbit for GPS coverage. Required before tracking waypoints.

The GPS Transmitter is a basic component of a GPS network, which is a building block of the GPS category.

Obtaining

The GPS Transmitters can be crafted in an Enhanced Crafting Table.

Usage and mechanics

The GPS Transmitter adds GPS network complexity equal to TierModifier * Height + TierBonus, based on the tier of the Transmitter and its Y-coordinate.

Tiers

The table below describes differences between tiers of Transmitters.
