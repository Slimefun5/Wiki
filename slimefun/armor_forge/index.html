Armor ForgeSlimefunDocumented

  • Multiblock
  • Gives you the ability to create powerful armor

A multiblock used to forge powerful armor sets. Add the components and right-click to assemble them.

The Armor Forge is in the Basic Machines category. It is a multiblock structure.

Obtaining

The Armor Forge is a multiblock structure, it consists of a dispenser and an anvil.
Note: It must be a standard anvil, damaged anvils will not work.

A complete setup should look like this:

You can also place an Output Chest next to the dispenser to collect your crafted armor. If there is no Output Chest, then it will be put in the dispenser.

Usage

The Armor Forge can be used to craft Armor and Magical Armor.
