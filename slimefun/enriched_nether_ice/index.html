Enriched Nether IceSlimefunDocumented

  • Resource
  • ☢ Radiation level: VERY HIGH
  • ⇨ Hazmat Suit required!

Enriched Nether Ice is a Resource that can be used to create Nether Ice Coolant Cells which can be used as coolant for the Nether Reactor.

Obtaining

Enriched Nether Ice is crafted with a Heated Pressure Chamber using 1 Plutonium and 1 Nether Ice.

Handling

Enriched Nether Ice is VERY HIGHLY Radioactive. Wearing a Hazmat Suit at all times while handling them is highly recommended.
