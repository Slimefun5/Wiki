The Tree Growth Accelerator is an Electric Machine which can be used to speed up the growth of nearby trees.
It's an End-Game machine but it can be useful for tree farms.

Tiers

It currently comes in only one tier.

Radius: 9x9
Buffer: 1024 J
Power Usage: 48 J/Sf Tick
