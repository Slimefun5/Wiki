Auto AnvilSlimefunDocumented

  • Machine
  • Automatically repairs items using Duct Tape.
  • ⇨ Repair Factor: 10%
  • ⇨ ⚡ 24 J/s

Automatically repairs items over time using energy, without an XP cost.

The Auto Anvil is an Electric Machine which can repair your tools and weapons.
It achieves this by using Duct Tape to repair your items based on the Repairing Efficiency of the machine.
