Permissions

This is a full list of all Permission nodes added by Slimefun5. Most of them are used for commands, so make sure to also see the wiki page about Commands.

Permissions for commands

Permission Description Default assignment
Slimefun5.cheat.items Allows you to use /sf give and /sf cheat OP
Slimefun5.cheat.researches Allows you to use /sf research OP
Slimefun5.stats.others Allows you to use /sf stats on other Players OP
Slimefun5.command.timings Allows you to use /sf timings OP
Slimefun5.command.teleporter Allows you to use /sf teleporter OP
Slimefun5.command.versions Allows you to use /sf versions OP
Slimefun5.command.guide Allows you to use /sf guide Everyone
Slimefun5.command.search Allows you to use /sf search Everyone
Slimefun5.command.open_guide Allows you to use /sf open_guide OP
Slimefun5.command.backpack Allows you to use /sf backpack OP
Slimefun5.command.charge Allows you to use /sf charge OP
Slimefun5.debugging Allows you to use /sf debug_fish OP

Permissions for blocks

Permission Description Default assignment
Slimefun5.inventory.bypass Allows you to open Slimefun5 machines that belong to other Players OP
Slimefun5.cargo.bypass Allows you to use Cargo Nodes that belong to other Players OP
Slimefun5.gps.bypass Allows you to use GPS devices that belong to other Players OP
Slimefun5.android.bypass Allows you to use Programmable Androids that belong to other Players OP
Slimefun5.android.upload-script Allows you to share Android Scripts with other Players on your Server OP
