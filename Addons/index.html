Addons

Want to spice up your Slimefun5-Server? Then you have come to the right place!
Here is a list of all Slimefun5 Addons (that we currently know of). You can install these addons to add even more content to your Slimefun5-based Minecraft Servers!

:trophy: Addon Jams

In 2020 we started hosting our very first "Slimefun5 Addon Jam" on our discord server.
We hope to make this a re-occurring thing. The basic premise is the following: At the start of the Jam we will announce a theme and every developer has a limited time frame to create a Slimefun5 Addon - from scratch - based on that theme. When the Jam has ended we will review their submissions, rate them and hand out prizes to the addons that performed the best.

:black_nib: Create your own addons!

Do you want to create your own Slimefun5 Addon? Check out this Developer Guide.

If you have made an Addon for Slimefun5 and want it to be listed on here, simply make a new pull request on our wiki repository. You can find a tutorial here: /wiki/Expanding-the-Wiki/.
If a pull request is not possible, then just create an Issue and select the "Addition" template:
https://github.com/Slimefun5/Wiki/issues
